## 🛠️ Featured Projects

### 🌾 [Cropsensy — MicroClimate Crop Detection](https://github.com/Pratik-padhi/Cropsensy-MicroClimate_Crop-detection)

ML-powered crop recommendation system that combines real-time microclimate data with soil nutrient profiles to recommend the optimal crop for your exact field conditions — right now.

- **Model:** Stacking Ensemble Classifier (Random Forest + Decision Tree + Logistic Regression meta-learner) with 9 engineered interaction features
- **Accuracy:** 96.8% test accuracy, 96.5% cross-validated across 22 crop types
- **Live Features:** Auto-detects location & pulls real weather data via browser geolocation; interactive soil sliders; rule-based soil diagnosis engine; fertilizer recommendations
- **Stack:** `Python` · `scikit-learn` · `pandas` · `NumPy` · `Flask` · `Netlify`
- 🌐 **[Live Demo](https://cropsensy.netlify.app)**
