LedgerLoop — Multi-Source Payment Reconciliation & Settlement Engine

Sep 2026

Schema-driven reconciliation across gateway, bank, and ledger records.

  • Python
  • Flask
  • SQLite
  • pytest
  • Gunicorn
  • Gemini
  • HTML/CSS/JavaScript
  • Render
  • Schema-driven engine that reconciles payment gateway, bank and internal ledger records through four escalating tiers, from a deterministic exact match up to guarded LLM adjudication.
  • Backed by 415 automated tests across 15 files, covering normalization, Decimal accounting and the fallback path of every matching tier. The suite runs offline with the LLM provider off, so a rerun is deterministic.
  • Settlement arithmetic uses Decimal, every upload is fingerprinted with SHA-256 for lineage, and each LLM verdict is validated server-side before acceptance. Anything ambiguous routes to human review.
  • Flask controller UI over 7 REST endpoints, with SQLite persistence and a Gunicorn deployment on Render.

CropSensy — Microclimate Crop Detection & Agronomy Advisory System

Apr – Aug 2026

Soil and microclimate inputs in, crop and fertilizer guidance out.

  • Python
  • scikit-learn
  • Flask
  • Pandas
  • NumPy
  • joblib
  • JavaScript
  • Leaflet
  • Netlify
  • Render
  • Stacking ensemble — Random Forest (100 trees), Decision Tree, and a Logistic Regression meta-learner — classifying 4 crops at 97.25% test accuracy and 97.10% ± 0.36% mean 5-fold cross-validation accuracy.
  • 27 features engineered from 7 soil and microclimate inputs the farmer types in. A 327-line validate.py rejects out-of-domain values and exits non-zero if any get through.
  • Seven Flask endpoints cover prediction, soil diagnosis and fertilizer recommendation. The frontend fills in location and live weather from Open-Meteo.
  • Model weights ship as joblib artifacts, so training and serving are decoupled. Frontend on Netlify, backend on Render.

Uber NCR Ride Analytics — Power BI Revenue & Operations Dashboard

Jun – Aug 2026

Five pages over Delhi NCR bookings, built for operating decisions.

  • Power BI
  • DAX
  • Power Query
  • Data Modeling
  • Bing Maps
  • 5-page Power BI report over 150,000 Delhi NCR bookings, surfacing INR 51.85M revenue, a 62% completion rate, INR 4.59M lost revenue and 176 pickup locations.
  • Power Query transforms the source data into the model; DAX measures on top of it isolate peak booking windows, the drivers behind cancellations, and vehicle-level trends across 7 vehicle types.
  • Bing Maps ranks pickup zones by volume and completion rate.
